Ultimate Number Guessing Game:
An interactive console-based Number Guessing Game built using Python.
This project enhances a basic guessing game with multiple game modes, multiplayer support, scoring, achievements, and statistics.

 FEATURES:
1. Game Modes
>Single Player – Play against the computer
>Multiplayer – 2 players compete turn-by-turn

2. Difficulty Levels
>Easy: 1–20 (7 attempts)
>Medium: 1–50 (6 attempts)
>Hard: 1–100 (5 attempts)

3. Gameplay Modes
>Normal Mode – Multiple attempts
>Sudden Death Mode – Only 1 attempt

4. Smart Features
> Hint System
>Odd/Even hint
>Range-based hint

5. Scoring System
>Based on remaining attempts
>Time-based bonus

6. Achievements
>First Try Genius
>Speed Runner
>No-Hint Master

7. Statistics Dashboard
>Attempts used
>Hints used
>Numbers guessed
>High scores

8. Multiplayer Features
> Turn-based gameplay
> Win tracking for each player
> Score system based on performance
> Live scoreboard display

9. Technologies Used
>Python
>Built-in modules:
random
time

10.How to Play
>Select Game Type (Single / Multiplayer)
>Choose Game Mode
>Select Difficulty Level
>Start guessing the number
>Follow hints and try to win with fewer attempts

11. Concepts Used
>Loops (while)
>Conditional statements (if-else)
>Exception handling (try-except)
>Data structures:
Lists
Sets
Dictionaries
Modular game logic
